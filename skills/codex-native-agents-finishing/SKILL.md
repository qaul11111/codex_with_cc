# Native Agent Finishing

Main uses record-run with matching spawn evidence and original host final text.
Settle every attempt, including interrupted attempts without a report. Use closed
only with the actual close_agent result; otherwise use verified original terminal
evidence and closeStatus=unsupported. Missing evidence remains unresolved.

Standard requires run-checks and record-main-review. Strict implementation needs
current spec/quality reviews and a final-verifier prepared against their exact runs.
The final worker uses verify-final-inputs; main runs verify after settlement.
Empty/pending workflows, changed source, stale reviews and incomplete lifecycle
cannot be accepted. Summarize verified results, test coverage and limitations.
Do not claim measured speed/cost gains from scheduling estimates or offline fixtures.
