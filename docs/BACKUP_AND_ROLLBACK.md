# Local Development Recovery

The plugin is a local user-scoped development installation from [qaul11111/codex_with_cc](https://github.com/qaul11111/codex_with_cc). Recover by disabling the local plugin in Codex, restoring the repository to a known commit, rerunning the verification commands in [VERIFICATION.md](VERIFICATION.md), and reloading the local plugin.

Do not mix plugin versions by copying individual skills or hooks into other directories. Keep one repository checkout as the installation source.
